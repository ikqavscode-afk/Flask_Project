# Заметки: Algorithms (динамическое программирование)

## Задача
Шесть классических задач: рюкзак 0/1, наибольшая общая подпоследовательность, разбиения числа, Флойд–Уоршелл, размен монет, редакционное расстояние.

## Ключевые решения
- **Две версии там, где это даёт выигрыш.** Рюкзак: одномерный массив (память O(W)) для значения и двумерная таблица для восстановления набора предметов. Редакционное расстояние хранит только две строки таблицы.
- **Восстановление ответа обратным ходом по таблице** (LCS, рюкзак) и матрица «следующая вершина» для путей в графе.
- **Докстринги с идеей и сложностью** у каждой функции.

## Трудности и выводы
- **Порядок циклов важен.** В рюкзаке 0/1 вместимость обходится от большей к меньшей, иначе предмет берётся повторно (получается рюкзак с неограниченными предметами). В размене монет порядок внешнего и внутреннего циклов решает, считаются ли перестановки разными способами.
- **Проверка по свойствам** надёжнее набора примеров: рюкзак сверяется с полным перебором на случайных данных, результат LCS — с проверкой «общая подпоследовательность нужной длины», число разбиений — с числом способов размена монетами номиналов 1..n.
- **Ошибки входа** (разная длина списков, отрицательные суммы) обрабатываются явно через `ValueError`.

## Что можно улучшить
- динамика по подмножествам (коммивояжёр);
- замеры времени для сравнения подходов;
- визуализация таблиц `dp` для объяснения алгоритмов.
