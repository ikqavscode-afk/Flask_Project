# Заметки: Flask Notes Blog

## Задача
Блог с заметками, регистрацией и входом. Основа для работы с миграциями и ручной реализацией сессий.

## Ключевые решения
- **Миграции Alembic.** Каждое изменение схемы (таблица заметок, подзаголовок, пользователи, владелец заметки) оформлено отдельной миграцией. Для SQLite добавление внешнего ключа сделано через `batch_alter_table`, потому что SQLite не умеет менять таблицу «на месте». Миграция проверена в обе стороны (upgrade и downgrade).
- **Защита заметок.** Собственный декоратор `login_required` на основе сессии, заметки привязаны к автору через `user_id`. Колонка допускает `NULL`, чтобы миграция не ломала уже существующие записи.
- **Хеши паролей и подписанные токены** (`werkzeug.security`, `itsdangerous`); секретный ключ берётся из переменной окружения.

## Трудности и выводы
- **Тесты стирали рабочую базу** (та же причина, что в Diary): подмена адреса базы после создания подключения не работала. Исправлено через `DATABASE_URL` и `conftest.py`. Заметил проблему благодаря пустой базе при проверке миграции, а не по падению тестов: тесты проходили, хотя работали с неверной базой.
- **Заметки сначала были общими для всех и доступными без входа.** Исправлено вместе с тестами на закрытый доступ и изоляцию.
- **Нет файла зависимостей.** Добавлен `requirements.txt` с точными версиями, чтобы установка воспроизводилась.
