# Algorithms: динамическое программирование

Шесть классических задач динамического программирования на Python: чистые функции с докстрингами, восстановлением ответа и тестами.

## Задачи

| Задача | Функции | Идея | Время | Память |
|---|---|---|---|---|
| Рюкзак 0/1 | `knapsack`, `knapsack_with_items` | `dp[w]` — лучшая стоимость при вместимости `w`; вместимость перебирается от большей к меньшей, чтобы предмет не использовался дважды. Версия с таблицей `dp[i][w]` возвращает ещё и взятые предметы | O(n·W) | O(W) / O(n·W) |
| Наибольшая общая подпоследовательность | `lcs_length`, `lcs` | `dp[i][j]` — длина LCS префиксов; при совпадении символов диагональ + 1, иначе максимум соседей. Строка восстанавливается обратным ходом | O(m·n) | O(m·n) |
| Разбиения числа | `count_partition` | способы набрать `n` слагаемыми от 1 до `n` (как размен монет) | O(n²) | O(n) |
| Кратчайшие пути между всеми вершинами | `floyd_warshall`, `floyd_warshall_paths`, `restore_path` | для каждой промежуточной вершины `k` пробуем улучшить путь `i → k → j`; матрица `nxt` позволяет собрать сам путь | O(V³) | O(V²) |
| Размен монет | `min_coins`, `count_coin_ways` | минимум монет для суммы и число наборов без учёта порядка | O(A·k) | O(A) |
| Редакционное расстояние | `edit_distance` | минимум вставок, удалений и замен (расстояние Левенштейна), хранятся две строки таблицы | O(m·n) | O(min(m, n)) |

## Использование

```python
from dp import knapsack_with_items, lcs, edit_distance

knapsack_with_items(50, [10, 20, 30], [60, 100, 120])  # (220, [1, 2])
lcs("AGGTAB", "GXTXAYB")  # "GTAB"
edit_distance("kitten", "sitting")  # 3
```

## Запуск демонстрации

```bash
python3 demo.py
```

## Тесты

```bash
pip install pytest
pytest -q
```

Тесты содержат известные значения (параметризованные), граничные случаи (пустые входы, нулевая вместимость, недостижимая сумма), проверки ошибок и сверку с полным перебором на случайных данных (рюкзак) и по свойствам (LCS — общая подпоследовательность нужной длины; редакционное расстояние симметрично; разбиения числа равны размену монет 1..n). Покрытие пакета `dp` — 100%.
