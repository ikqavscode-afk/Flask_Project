# CLI Shop

Консольный симулятор магазина на Python. Построен на классах (ООП): каталог товаров, корзина и собственные реализации алгоритмов сортировки.

## Возможности

- просмотр каталога товаров;
- добавление товара в корзину и удаление из неё;
- добавление и удаление товаров каталога с проверкой ввода;
- сохранение каталога в `data/catalog.json`: изменения не теряются между запусками (при отсутствии или повреждении файла загружается стандартный каталог);
- подсчёт общей стоимости и веса;
- сортировка корзины по цене, весу или категории, по возрастанию или убыванию;
- четыре алгоритма сортировки на выбор: пузырьком, вставками, быстрая, слиянием;
- режим «показывать шаги» — пошаговый вывод работы выбранного алгоритма.

## Структура

```
cli-shop/
├── main.py             # точка входа
├── shop/
│   ├── models.py       # Product, Catalog
│   ├── cart.py         # Cart
│   ├── storage.py      # сохранение и загрузка каталога (JSON)
│   ├── sorting.py      # SortAlgorithms
│   └── cli.py          # ShopApp: текстовое меню
├── tests/
├── pytest.ini
└── README.md
```

| Класс | Назначение |
|---|---|
| `Product` | товар: название, категория, цена, вес, описание |
| `Catalog` | хранилище товаров: добавление, правка, удаление, поиск без учёта регистра |
| `Cart` | корзина: добавление, удаление, итоговая цена и вес, вывод |
| `SortAlgorithms` | реализации сортировок с функцией ключа и режимом пошагового вывода |
| `ShopApp` | текстовое меню и обработка пользовательского ввода |
| `save_catalog` / `load_catalog` | запись и чтение каталога в JSON (`shop/storage.py`) |

## Как добавить алгоритм сортировки или критерий

Меню строится из реестров в `shop/sorting.py`, поэтому интерфейс менять не нужно:

1. Напишите функцию по образцу существующих: `my_sort(items, key_func, reverse=False, show_steps=False)`; для сравнения используйте `precedes(a, b, reverse)`.
2. Добавьте пару `("Подпись в меню", my_sort)` в список `ALGORITHMS`. Новый критерий добавляется в `CRITERIA` так же: подпись, имя, функция ключа.
3. Тесты сортировок берут алгоритмы из реестра, поэтому новая функция автоматически проверяется на всех критериях и порядках.

## Запуск

Нужен только Python 3, внешних зависимостей нет.

```bash
python3 main.py
```

## Тесты

```bash
pip install pytest
pytest -q
```

Тесты проверяют модели и корзину, все четыре сортировки (сравнение с `sorted()` по каждому критерию и порядку, неизменность исходного списка, пустые и одиночные списки), а также сохранение и загрузку каталога (в том числе повреждённый файл), сценарии меню и проверку ввода. Тесты работают с временной папкой и не трогают настоящий `data/catalog.json`. Покрытие пакета `shop` — около 94%.
