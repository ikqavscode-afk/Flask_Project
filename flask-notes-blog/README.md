# Flask Notes Blog

Веб-приложение для заметок на Flask с регистрацией и входом пользователей.

## Возможности

- регистрация с проверкой уникальности логина и email;
- вход по логину и паролю, сообщения об ошибках через `flash`;
- пароли хранятся в виде хеша (`werkzeug.security`);
- токен сессии на основе `itsdangerous`;
- создание и просмотр заметок (заголовок, подзаголовок, текст);
- заметки доступны только после входа и принадлежат автору: каждый видит только свои;
- выход из аккаунта (`/logout`);
- миграции базы данных (Flask-Migrate / Alembic).

## Технологии

Python, Flask, Flask-SQLAlchemy, Flask-Migrate, SQLite, Jinja2, HTML/CSS, pytest.

## Структура

```
flask-notes-blog/
├── app.py            # приложение, модели, маршруты
├── migrations/       # миграции Alembic
├── static/           # стили и изображения
├── templates/        # шаблоны Jinja2
├── conftest.py       # настройка тестов (БД в памяти)
├── test_app.py       # тесты
└── requirements.txt
```

## Маршруты

| URL | Метод | Описание |
|---|---|---|
| `/` | GET | главная страница |
| `/home` | GET | страница с кнопками входа и регистрации |
| `/register` | GET, POST | регистрация |
| `/login` | GET, POST | вход |
| `/notes` | GET, POST | свои заметки и создание новой (нужен вход) |
| `/logout` | GET | выход |

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export SECRET_KEY="длинная-случайная-строка"
flask --app app db upgrade
flask --app app run --debug
```

Приложение откроется на http://127.0.0.1:5000.

## Тесты

```bash
pip install pytest
pytest -q
```

Тесты используют отдельную базу в памяти (адрес задаётся переменной `DATABASE_URL` в `conftest.py`) и проверяют: регистрацию, вход, ошибку при неверном пароле, хеширование пароля, закрытый доступ к заметкам без входа, изоляцию заметок между пользователями и выход.
